### Цель проекта:

Разработка и экспериментальное исследование методов ранжирования и отбора проверяемых 
статистических фактов о баскетбольных матчах, учитывающие редакционную ценность и 
разнообразие фактов для подготовки аналитических материалов.

### Структура:

```
basketball-fact-ranking/
├── backend/                            # FastAPI сервис
│   ├── app/                            # API и бизнес логика
│   │

│   ├── poetry.lock                     # Зависимости в моменте?

│
├── docs/                               # Документация

├── docker-compose.yml                  # Сборка всех контейнеров
├── .env                                # Значения конфигурации

└── README.md                           # Основное описание проекта
```
